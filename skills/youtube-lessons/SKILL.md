# YouTube lessons

When the owner asks to open a lesson/video on YouTube:

1. Call `youtube_open_lesson` with the topic (e.g. `урок по python`).
2. Do **not** click the first result yourself — it is often «Реклама» (Coursera etc.).
3. The mission scrolls, skips ads & Shorts, ranks organic `/watch` videos, opens one, verifies URL.
4. If tool returns ERROR or ad landing — say so honestly and retry with a clearer query. Never pretend success.

Also apply the same brain elsewhere: scroll past ads, verify the page matches the goal, no checkbox DONE.
