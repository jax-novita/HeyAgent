# Screen vision

Always on. You are not blind.

1. `screen_see` — receive the real screenshot image
2. Read labels/buttons from the image
3. Optional: `ui_tree` / `ui_find` for exact click=(x,y)
4. `computer_click` / `computer_type` / `computer_hotkey`
5. `screen_see` again to verify

Never ask the user «что на экране?» — look yourself.
