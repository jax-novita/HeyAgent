================================================================================
  HeyAgent — справочник команд
================================================================================
Все команды запускаются из папки проекта:
  cd C:\Users\Marat\Documents\Projects\HeyAgent

На Windows в PowerShell, если npm ругается на скрипты, используй:
  npm.cmd ...
  или: npx hey ...

Первый запуск:
  npm.cmd install
  npm.cmd run build
  npx hey onboard


================================================================================
  1. КОМАНДЫ CLI (терминал)
================================================================================

npx hey help
  Показать краткую справку по командам CLI.

npx hey onboard
  Первичная настройка агента:
  — задать имя агента;
  — выбрать пиксельный скин (аватар);
  — выбрать persona (friendly / engineer / concise);
  — подключить провайдера модели и API-ключ;
  — выбрать модель по умолчанию;
  — smoke-test модели.

npx hey avatars
  Показать галерею всех 12 пиксельных скинов в терминале.

npx hey chat
  Интерактивный чат с агентом в терминале.
  Агент может вызывать tools (браузер, файлы, поиск, блокнот и т.д.).

npx hey chat <sessionId>
  Продолжить существующую сессию чата по ID.

npx hey ask "текст"
  Один вопрос / одна задача без интерактивного режима.
  Пример: npx hey ask "какая погода в Москве?"

npx hey status
  Статус агента: имя, аватар, persona, текущая модель, интеграции.


--------------------------------------------------------------------------------
  Модели (LLM)
--------------------------------------------------------------------------------

npx hey models list
  Список провайдеров и доступных моделей
  (OpenAI, Anthropic, Google, DeepSeek, OpenRouter, Ollama, custom и др.).

npx hey models set <provider/model>
  Установить модель по умолчанию.
  Пример: npx hey models set openai/gpt-4.1-mini
  Пример: npx hey models set ollama/llama3.2

npx hey models auth <provider>
  Сохранить API-ключ (или base URL для custom) для провайдера.
  Пример: npx hey models auth openai
  Пример: npx hey models auth anthropic

npx hey models test
  Проверить, что текущая модель отвечает (smoke-test).

--------------------------------------------------------------------------------
  Telegram — управление агентом через бота
--------------------------------------------------------------------------------

Схема:
  Ты пишешь боту в Telegram
    → gateway на твоём ПК получает сообщение
    → HeyAgent выполняет задачу на компьютере
    → ответ приходит обратно в Telegram

npx hey telegram setup
  Сохранить токен бота от @BotFather.

npx hey telegram pair
  Привязать ТОЛЬКО твой личный чат (после /start боту).
  Подхватывает chat_id автоматически.

npx hey telegram status
  Показать: включён ли бот, есть ли pair, нужен ли gateway.

npx hey gateway start
  ОБЯЗАТЕЛЬНО держать запущенным, пока управляешь через Telegram.
  Без gateway бот «молчит».

Как пользоваться после настройки:
  1) Открой своего бота в Telegram
  2) Пиши обычным текстом, как в hey chat:
       какая погода в Москве?
       открой блокнот и напиши список дел
       напиши Ренату в телеграм привет
  3) Опасные действия (удаление, shell) спросят Approve/Deny кнопками

Важно:
  — Компьютер должен быть включён, gateway запущен
  — Бот = пульт; «напиши Ренату» открывает Telegram Desktop на ПК
  — Не свети bot token публично; при утечке — /revoke в @BotFather


--------------------------------------------------------------------------------
  Gateway / демон
--------------------------------------------------------------------------------

npx hey gateway start
  Запустить gateway (HTTP/WebSocket на порту 28789).
  Нужен для desktop tray-приложения и Telegram-канала.

npx hey daemon install
  Показать инструкции автозапуска gateway
  (Windows Task Scheduler / macOS launchd / Linux systemd).
